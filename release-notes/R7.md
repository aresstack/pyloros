# Release 7 — Public ACP Registry Installer for Managed ACP Providers

## Summary

Release 7 adds Pyloros-native management of public ACP Registry agents: load, cache, validate, install, configure, and run agents from the public ACP Registry as managed provider subprocesses with Pyloros MCP Aggregator injection.

## Features

### R7-01: ACP Registry Client & Cache
- Loads the public ACP Registry from `cdn.agentclientprotocol.com`
- Local JSON file cache with fallback on network errors
- Validation of registry entries (id, name, version, description, distribution)

### R7-02: Distribution Resolver
- Resolves `binary`, `npx`, and `uvx` distribution types
- Platform-aware binary target selection (linux/darwin/windows × x86_64/aarch64)
- Deterministic `InstallPlan` without downloading

### R7-03: Installed Agent Store
- Persistent JSON store for installed agent metadata
- Atomic file writes, corrupted entry skipping
- CRUD operations: save, list, findById, remove, setEnabled

### R7-04: Managed ACP Provider Generation
- Converts installed agents to `AcpProviderConfiguration` objects
- Validates prefix format, agent tool views and cross-provider collisions
- Injects `PYLOROS_MCP_URL` and bearer token into agent environment

### R7-05: Install / Update / Uninstall Lifecycle
- `AgentLifecycleService` orchestrator with rollback semantics
- Binary download/extraction with path traversal and SSRF prevention
- Preflight archive entry validation before extraction
- Transactional install: cleanup on failure
- Audit logging of all operations

### R7-06: Auth Flow Support
- `AgentAuthMethod` (NONE, AGENT_AUTH, TERMINAL_AUTH) and `AgentAuthStatus` (NOT_REQUIRED, REQUIRED, CONFIGURED)
- Auth requirements from registry metadata forwarded to installed agent
- Auth-required agents blocked at provider generation with structured error
- No credential storage in Pyloros

### R7-07: Headless Management API
- 8 native tools: list registry agents, refresh, install, update, uninstall, configure, list installed, get status
- Structured JSON output for all operations
- Auth status visible in management tools
- No secret leakage in tool outputs

### R7-08: Security Hardening & Audit
- Security checklist with 20 verified rules
- Documentation: agent auth, security checklist
- Full test suite: 50+ tests across all R7 components

## Security

- No automatic installation or execution
- External agents default to prefixed namespaces (not root)
- agentToolView is always non-public
- ACP session/new injects mcpServers.pyloros with trusted view token
- Recursion protection across all providers
- Auth-required agents cannot silently operate
- No credential storage or logging

## Out of Scope (→ R8)
- Universal Manager Agent
- WorkGraph / Planner / Delegation / Review Loop
- A2A Orchestration
- LLM selection or LangChain/Ollama integration
